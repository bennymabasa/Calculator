# Calculator 🧮

A clean, responsive calculator application built with pure HTML, CSS, and JavaScript.

![Calculator Preview](https://via.placeholder.com/600x400?text=Calculator+App) <!-- Replace with actual screenshot later -->

## ✨ Features

- ✅ Basic arithmetic operations (Add, Subtract, Multiply, Divide)
- ✅ Clear (C) button to reset
- ✅ Responsive design that works on desktop and mobile
- ✅ Clean, modern UI
- ✅ Keyboard support ready (can be extended)

## 🛠 Technologies Used

- **HTML5** - Semantic structure
- **CSS3** - Modern styling, Flexbox, responsive design
- **JavaScript (ES6)** - Logic and interactivity

## 💻 Live Demo

Open `index.html` in your browser, or [view the live version](https://bennymabasa.github.io/Calculator) (once GitHub Pages is enabled).

## 📦 How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/bennymabasa/Calculator.git
   ```
2. Navigate to the project folder:
   ```bash
   cd Calculator
   ```
3. Open `index.html` in your preferred browser.
